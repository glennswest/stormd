# Research — 2026-10-13 (stormcentral #628)

Window: since 2026-10-06. Read-only; no code changed.

## 1. Upstream dependencies

Locked: russh 0.46.0 (workspace; russh-sftp vendored), rustls 0.23.37, tokio 1.49.0,
axum 0.8.8, hyper 1.8.1, reqwest 0.12.28, ratatui 0.29.0.

- **rustls — RUSTSEC-2026-0285** (Medium, CVSS 5.3): TLS 1.3 handshake messages accepted at the
  wrong encryption level. Affects 0.23.13–0.23.44, fixed in **0.23.45**. stormd's API TLS (#32)
  uses rustls 0.23.37, so it is affected. Advisory last modified 2026-10-12.
  <https://rustsec.org/advisories/RUSTSEC-2026-0285.html> → filed as an issue.
- **russh — RUSTSEC-2026-0153 / -0154** (High, 7.5, DoS): unchecked `CryptoVec` growth and
  unbounded agent-frame allocation; patched in 0.60.3. Before 0.58.0 the remote path (transport
  packet reads, zlib decompression) is reachable. Advisories modified 2026-10-12.
  <https://rustsec.org/advisories/RUSTSEC-2026-0153.html>,
  <https://rustsec.org/advisories/RUSTSEC-2026-0154.html>
- **russh CVEs (from Debian tracker / CVE feeds, not checked against the upstream advisory):**
  CVE-2026-42189 pre-auth DoS in the keyboard-interactive handler of servers (< 0.60.1);
  CVE-2026-46702 oversized decompressed packets (0.34.0 – < 0.61.1); CVE-2026-73429 malformed
  KEX reply crashes a client (< 0.62.4); CVE-2026-68930 channel callbacks for unopened IDs (< 0.62.5).
  <https://tracker.debian.org/pkg/rust-russh>, <https://cvefeed.io/vuln/detail/CVE-2026-68930>
  stormd runs a russh **server** on 0.46 (`ssh.rs`), so the server-side ones apply (keyboard-interactive
  is not wired by stormd, which lessens CVE-2026-42189; compression is russh default).
  → filed as an issue. The upgrade crosses many minor versions and the vendored russh-sftp
  must follow.
- tokio: a Dependabot PR elsewhere mentions 1.53.x (2026-10-03); no tokio advisory found.
  axum / hyper / reqwest / ratatui: no advisory found. `cargo audit` was not run (no cargo here);
  a real `cargo audit` in a build job would confirm.
- Images pulled / npm: not checked beyond `web/package.json` (svelte ^5, vite ^6); nothing found.
